# Lot Prix — plan d'exécution

Spec (fait foi) : `docs/superpowers/specs/2026-09-27-prix-design.md` (validée
par Ilane le 27/09/2026). Branche `feature/phase-3-prix` (session B). Dix

« go » d'Ilane sur ce plan.**

## Contraintes communes

- `CLAUDE.md` fait foi : `extract`, `normalize`, `rules` purs (ni FastAPI, ni
  SQLAlchemy, ni httpx ; dataclasses ; tests sans base ni réseau) ; `api`
  n'importe que `ingest` et `app.core` ; routeur = valider, appeler,
  sérialiser ; aucune règle dans le front.
- Numéros réservés : migration `0013`, règles `R19`-`R25`, réglages
  `prix_…`, journal `grille_*` / `prix_*`, routes `/api/grilles/…` et
  `/api/prix/…`, pages `/prix` et `/fournisseurs/:id/prix`.
- Fichiers partagés avec la session A : ajout à la suite seulement, une ligne
  quand c'est possible (`extraction_bl.py`, `corrections.py`,
  `api/__init__.py`, `App.tsx`, `Gabarit.tsx`, `FicheFournisseur.tsx`,
  `ProblemeDetail.tsx`, `ui/libelles.ts`, `lib/journal.ts`, `parametres.py`,
  `anomalies.py`, `commun.py`, `a_traiter.py`, `engine.py`, `models.py`,
  `schemas.py`, `openapi.json`, `schema.d.ts`, `app/cli.py`).
- Données de test **inventées** ; les tests génèrent leurs fichiers Excel ;
  aucune valeur des grilles réelles dans le code, les tests, les journaux ni
  les messages. Seul `tests/test_grilles_reelles.py` lit la grille Cedeo de
  `tests/fixtures/grilles/` (sauté si absente) sans jamais afficher une
  valeur.
- Textes à l'écran en français courant, sans code de règle ni mot technique.
- Tests écrits d'abord. Avant chaque commit : ruff, format, mypy, suite
  complète sous `flock /tmp/habitat_reno-tests.lock`, typecheck et build du
  front. Hook pre-commit jamais contourné.
- Sous-agents Sonnet, **un implémenteur à la fois** ; chaque tâche relue
  (conformité à la spec, puis qualité) et corrigée avant son commit.
